# HackTrack

This is a Next.js application for the HackTrack hackathon event, built with Firebase and Genkit.

## Core Features

- **Event Schedule**: View the complete event schedule.
- **Registration**: Register as a participant.
- **Live Announcements**: Stay updated with real-time announcements.
- **Project Submissions**: Submit your hackathon project.
- **Judging**: A dashboard for judges to review and score projects, featuring AI-powered feedback summaries.
- **Team Formation**: Find teammates to collaborate with.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.
